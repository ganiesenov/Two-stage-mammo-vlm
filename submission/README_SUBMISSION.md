### Почему файлы 1 и 3 не собраны

**Редактируемого исходника рукописи не существует.** Поиск по `.docx`, `.doc`, `.tex`,
`.odt`, `.rtf` в репозитории, `Downloads`, `OneDrive`, `Documents` и `Desktop` дал только
скомпилированный PDF препринта:

`/mnt/c/Users/juman/Downloads/Two_Stage_Synthetic_to_Real_Transfer_Learning_..._Models.pdf`
(15 страниц, 26.04.2026).

Собрать из PDF «чистую рукопись» невозможно без восстановления статьи заново — это была бы
не правка, а переписывание, с риском внести расхождения с опубликованным препринтом.
Нужен исходник в Word или LaTeX; вероятно, он в Overleaf, Google Docs или у соавтора.

Из этого следует прямой и важный вывод: **все правки ревизии существуют только в ответе
рецензентам и во внутренних документах, но не в самой статье.** Ни замена метрики
галлюцинаций на 0/52, ни вывод свипа об эквивалентности, ни объяснение Table 4 через ёмкость
адаптера в текст рукописи не внесены — вносить было некуда.

Чтобы собрать файлы 1 и 3, нужен исходник рукописи (Word или LaTeX). После его появления
правки применяются по спецификации `manuscript_edits.md` в этом каталоге — она составлена
так, чтобы каждая правка была применима механически и одновременно служила основой
для подсветки в файле 3.

## Что заморожено и почему

| Что | Блокируется чем |
|---|---|
| Абстракт и список вкладов | стаж радиологов + строка лицензии DMID |
| Reader study (R1.10, R2.4) | радиологи не назначены, чтения не проводилось |
| Supplementary: перевыкладка изображений | точная строка лицензии DMID (Figshare отдаёт 403 автоматическому запросу) |

Готовая формулировка ключевого пункта абстракта лежит в `POINT_BY_POINT_RESPONSE.md`,
раздел «Заготовка для абстракта — НЕ ВНОСИТЬ до разблокировки».

### ⛔ Отдельное предупреждение по R1.10

Раздел R1.10 содержит текст Methods, написанный **в прошедшем времени**, как будто
исследование с двумя радиологами проведено. Оно **не проводилось**. В файле стоит
блокирующая пометка. Перед подачей раздел либо подтверждается фактически проведённым
чтением, либо переписывается на «инструмент подготовлен, оценка радиологами в текущей
версии отсутствует и заявлена как ограничение». Подача текущего текста означала бы
утверждение о непроведённой работе.

## Порядок сборки, когда исходник появится

1. Применить правки из `manuscript_edits.md` к исходнику → **файл 1** (чистый, без пометок).
2. Тот же набор правок применить с включённым отображением исправлений или с подсветкой
   → **файл 3** (marked-up, в related files).
3. Перевести `POINT_BY_POINT_RESPONSE.md` на английский, убрать внутренние пометки
   (`[НУЖЕН ЧЕЛОВЕК]`, `[ЖДЁТ ЧТЕНИЯ]`, блок «Заготовка для абстракта», блокирующие
   баннеры) и экспортировать → **файл 2** (PDF).

Порядок именно такой: файл 3 получается из того же набора правок, что и файл 1, иначе
подсвеченная версия разойдётся с чистой.
